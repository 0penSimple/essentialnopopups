Good to know

  • This tool uses advanced web technology to directly access the files and folders stored on your computer, so your files, folder names, and photos are never uploaded, copied, or sent over the internet.
  • Some browsers like Brave, Firefox, or Safari may restrict or block direct folder editing entirely. For the best experience, we recommend using Google Chrome or Microsoft Edge.

    • Features Overview
  • Categorizing & Sorting: Automatically organizes loose files into subfolders by file type, custom timeframes (Year, Month, Day), or custom rules.
  • Find Duplicates: Scans all subfolders using digital file signatures to detect and safely clean identical file copies.
  • Batch Rename: Updates multiple filenames at once with custom prefixes, text replacements, date stamps, or sequential numbers.
  • Folder Icon & Color: Designs custom icons and folder colors to personalize your desktop folders on Mac, Windows, or Linux.
  • Session Undo: Easily reverse your last sorting action with one click to restore files to their original locations.
